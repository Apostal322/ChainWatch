# ChainWatch: synthetic demo

This Space runs the ChainWatch replay dashboard on **synthetic data** with the
Elliptic++ schema. Every number in the dashboard describes that synthetic data, not real
Bitcoin activity. The research results shown under "Models & experiments" come from
committed reports on the real dataset.

Source code, research write-up and limitations:
<https://github.com/Apostal322/ChainWatch>
